# Best Hello World

A tiny CLI that prints Hello World examples for popular programming languages.

## Usage

Run interactively:

```bash
python3 hello_world_cli.py
```

Print a specific language:

```bash
python3 hello_world_cli.py python
python3 hello_world_cli.py js
python3 hello_world_cli.py rust
```

List supported languages:

```bash
python3 hello_world_cli.py --list
```

## Supported Languages

- C
- C++
- C#
- Go
- Java
- JavaScript
- Kotlin
- PHP
- Python
- Ruby
- Rust
- Swift
- TypeScript
